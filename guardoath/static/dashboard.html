Checks on this record

Each check is a field on the tenant record. Choose what happens when a check finds something, or turn it off. Select What is this? under any check for what it looks for and why you would use it. Changes apply from the next check.

Off
The check does not run.
Block
A finding stops the message or answer.
Flag
A finding is reported and marked for review; your application decides what to do.
Allow
A finding is reported, and the message or answer goes through.
Redact
Personal data only: what is found is replaced, and the checks run again on the result.
